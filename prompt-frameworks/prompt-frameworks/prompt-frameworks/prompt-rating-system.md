# Prompt Rating System

## Clarity (1-10)

Does the AI clearly understand the objective?

## Reusability (1-10)

Can the prompt be reused with different inputs?

## Specificity (1-10)

Does it provide enough context?

## Output Quality (1-10)

Will the output be actionable?

## Total Score

40/40 = Elite Prompt

35+ = Production Ready

30+ = Good

Below 30 = Improve
