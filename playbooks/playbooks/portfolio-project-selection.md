# Portfolio Project Selection Framework

## Goal

Select projects that maximize:

- Learning
- Employability
- Visibility
- Business value

Avoid projects that look impressive but provide little career return.

## 1. Market Demand

Ask:

- Are companies hiring for this skill?
- Is it relevant to Data Analysts?
- Is it relevant to Business Analysts?
- Is it relevant to BI professionals?

Score: /10

---

## 2. Technical Skill Demonstration

Does the project demonstrate:

- Excel
- SQL
- Python
- Statistics
- Power BI

Score: /10

---

## 3. Business Impact

Can the project answer:

- Revenue questions?
- Customer behavior questions?
- Operational efficiency questions?
- Strategic decision-making questions?

Score: /10

---

## 4. Portfolio Visibility

Will this project stand out?

Can it be shared on:

- GitHub
- LinkedIn
- Resume
- Personal website

Score: /10

---

## 5. Storytelling Potential

Can I explain:

- Problem
- Analysis
- Findings
- Recommendations

In a compelling way?

Score: /10

## 6. Monetization Potential

- Consulting service
- Dashboard service
- Training material
- Client case study
- SaaS idea
