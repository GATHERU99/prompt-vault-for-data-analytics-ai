# GitHub Skim Like a Nerd

## Goal

Evaluate a repository in under 30 minutes.

---

## Minute 0-2: README Test

Questions:

- What problem does it solve?
- Who is it for?
- Is the value proposition obvious?
- Does it have screenshots or demos?

Decision:

- Clear → Continue
- Confusing → Reject

---

## Minute 2-5: Activity Check

Review:

- Stars
- Forks
- Issues
- Pull Requests
- Recent commits

Questions:

- Is it maintained?
- Is there an active community?
- Are issues being addressed?

Decision:

- Active → Continue
- Dead → Proceed cautiously

---

## Minute 5-10: Architecture Scan

Inspect:

- Folder structure
- Dependencies
- Setup instructions

Questions:

- Can I understand the architecture?
- Is the code modular?
- Is it production quality?

Decision:

- Clean → Continue
- Messy → Flag

---

## Minute 10-15: Business Potential

Ask:

- Could this become a service?
- Could this become a SaaS?
- Could this solve a client problem?
- Could Metacom Virtuals use it?

Score:
1-10

---

## Minute 15-20: Learning Potential

Ask:

- What skills will I learn?
- Does it expose me to new technologies?
- Is it worth studying deeply?

Score:
1-10

---

## Minute 20-25: Monetization Opportunities

List:

- Consulting
- SaaS
- Templates
- Automation
- Internal tools
- Training

Score:
1-10

---

## Minute 25-30: Final Decision

Choose:

- Study
- Fork
- Use
- Adapt
- Monetize
- Ignore

Write one paragraph explaining why.
